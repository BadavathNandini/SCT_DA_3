# HR Employee Attrition Analysis Dashboard

## Overview

This project is an interactive Power BI dashboard developed to analyze employee attrition patterns and identify factors influencing employee turnover.

## Objective

The objective of this project is to provide meaningful insights into employee attrition by analyzing various factors such as department, age group, gender, and job role.

## Tools Used

* Power BI
* Microsoft Excel / CSV Dataset
* Data Visualization
* DAX Measures

## Key Features

* Total Employees KPI
* Attrition Count KPI
* Attrition Rate KPI
* Department-wise Attrition Analysis
* Age Group Analysis
* Gender-wise Attrition Analysis
* Job Role Analysis
* Interactive Slicers and Filters

## Dashboard Insights

* Attrition Rate: 16.12%
* Sales department shows higher attrition compared to other departments.
* Employee attrition varies across different age groups and job roles.
* Interactive filters enable detailed exploration of employee data.
